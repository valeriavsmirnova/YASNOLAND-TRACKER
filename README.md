# YASNOLAND Rewards Tracker

Веб-интерфейс для учеников и родителей языковой студии «Ясноленд». После входа кабинет разделён на вкладки **Rewards** и **Progress**. Rewards показывает мотивационные результаты, баланс YASNOLAND Dollars, историю месяцев, покупки и доступные подарки. Progress показывает академические навыки и комментарии преподавателя.

## Архитектура и данные

Единственный источник истины — Excel-книга. Преподаватель редактирует её и синхронизирует с Яндекс Диском. При каждом открытии и по кнопке **Refresh data** сайт запрашивает временную ссылку через официальный endpoint `cloud-api.yandex.net/v1/disk/public/resources/download` с параметром `path=/yasnoland-tracker.xlsx`, загружает ArrayBuffer и читает его через SheetJS. Публичный ресурс: https://disk.yandex.ru/d/AH9oiy7YcSWXtA. Параметр `path` обязателен, потому что публичная ссылка ведёт на папку, а загрузка корня вернула бы ZIP-архив.

Если браузер или Яндекс Диск блокирует запрос, приложение честно показывает режим `local fallback` и читает статическую копию `public/yasnoland-tracker.xlsx`. Это позволяет GitHub Pages продолжать работать, но данные в такой копии обновляются только при новой публикации сайта.

Используются листы `Students`, `Lists`, `REWARDS`, `LESSONS`, `BALANCE`, `PURCHASES`, `PROGRESS`, `GIFTS`. Лист `PROGRESS` содержит помесячные Vocabulary, Grammar, Reading, Listening, Speaking, Homework, Overall Progress, Unit / Topics и Comment. Общий Academic Progress вычисляется только по пяти академическим навыкам — Homework в него не входит. Приложение ничего не записывает в книгу и не использует Firebase или localStorage.

## Правила

- За урок: 3 критерия дают 2 stamps, 2 критерия — 1 stamp, 0–1 — 0 stamps.
- За завершённый месяц: 75–100% stamps дают 2 Dollars, 50–74% — 1 Dollar, меньше 50% — 0.
- Интерфейс показывает уже рассчитанные Excel значения `Stamp` и `Dollars`, не перезаписывая их.
- `BALANCE` содержит Earned, Spent и Balance; `GIFTS` определяет ассортимент и цены.

## Работа с Excel

Добавление ученика: новая строка в `Students` с уникальным Student ID, именем, группой, курсом, кодом доступа и статусом Active. Добавление урока: новая строка в `LESSONS`; соответствующая месячная строка ведётся в `REWARDS`. Добавление подарка: новая строка в `GIFTS`. Покупка регистрируется в `PURCHASES`, а суммы актуализируются в `BALANCE`.

Для изображения подарка положите файл `G001.jpg`, `G002.jpg` и т. д. в `public/images/` (ID должен совпадать с `Gift ID`) или заполните `Image URL`. При отсутствии файла отображается нейтральный placeholder.

## Запуск

```bash
npm install
npm run dev
npm run build
```

Сборка появляется в `dist/`. `base: './'` в Vite делает пути совместимыми с подпапкой GitHub Pages. Workflow `.github/workflows/deploy.yml` публикует `dist` при push в `main`; в настройках репозитория выберите Pages → Source → GitHub Actions.

## Ограничение входа

Student ID + PIN проверяются в браузере по скачанной книге. После успешного входа браузер сохраняет только Student ID, чтобы на этом устройстве не требовалось повторно вводить PIN; кнопка `Exit` удаляет сохранённый вход. Учебные данные в localStorage не сохраняются и каждый раз читаются из Excel. Это демонстрационная клиентская авторизация: она не скрывает данные книги и не является production security. Для реального защищённого доступа нужен backend и полноценная аутентификация (например, будущий переход на Firebase Auth или другой серверный сервис), а публичный Excel следует заменить защищённым API.
