# Пояснительная записка

YASNOLAND Rewards Tracker решает простую проблему: таблица с результатами удобна преподавателю, но сложна и неинтересна ребёнку и родителю. Веб-приложение превращает данные Excel в понятный личный кабинет для учеников языковой студии примерно 7–14 лет.

Преподаватель продолжает работать в привычном Excel: добавляет учеников и уроки, отмечает English Only, Homework и Class Rules, регистрирует награды и покупки. Файл синхронизируется с Яндекс Диском. Сайт загружает его при открытии или по кнопке обновления, но никогда не изменяет исходную книгу.

Ученик входит по своему ID и коду, после чего видит только свой экран: текущий месяц, число уроков и stamps, оценки по трём критериям, историю завершённых месяцев, заработанные и потраченные YASNOLAND Dollars. За выполнение всех трёх критериев урок приносит 2 stamps, двух — 1 stamp. Итог завершённого месяца может принести до двух Dollars в зависимости от доли собранных stamps; интерфейс использует итоговые значения из Excel.

Gift Fair превращает результат в видимую цель. Карточки сразу показывают, какой подарок уже доступен, сколько Dollars осталось накопить или что временно отсутствует. Это связывает регулярные учебные действия с понятным прогрессом без перегруженного или слишком детского оформления.

Связка Excel + веб-интерфейс выбрана потому, что не требует менять рабочий процесс преподавателя, а ученику даёт современное представление тех же данных на телефоне или компьютере. В учебной версии PIN проверяется на стороне браузера и не является защищённой системой авторизации.
